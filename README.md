# Loryn Work Optimization

Planning and delivery repository for a mobile-first CRM and workflow system for an independent window-covering sales consultant.

The project evaluates and configures an existing low-cost CRM before considering custom software. It covers Costco/Centah opportunities, independently sourced leads, prospecting, follow-up, post-sale handoff, installation checks, and past-customer outreach.
