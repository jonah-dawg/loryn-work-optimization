# Loryn Work Optimization

Planning and delivery repository for a mobile-first CRM and workflow system for an independent window-covering sales consultant.

The project evaluates and configures an existing low-cost CRM before considering custom software. It covers Costco/Centah opportunities, independently sourced leads, prospecting, follow-up, post-sale handoff, installation checks, and past-customer outreach.

## Start here

1. Read [`project-control/CURRENT_STATE.md`](project-control/CURRENT_STATE.md) for the exact restart point.
2. Read the latest entry in [`project-control/SESSION_LOG.md`](project-control/SESSION_LOG.md).
3. Read the linked approved artifact and the relevant portion of [`deliverables/window-sales-operations-master-plan.md`](deliverables/window-sales-operations-master-plan.md).
4. Follow [`project-control/GUIDED_WORKFLOW.md`](project-control/GUIDED_WORKFLOW.md) for interactive work, validation, sign-off, and handoff.

## Collaborator handoff

The repository preserves the durable project state, decisions, rules, and exact restart point. It does not transfer a Codex or ChatGPT chat transcript to another person.

For asynchronous guided questions in the ChatGPT mobile app, use [`project-control/COLLABORATOR_PACKET.md`](project-control/COLLABORATOR_PACKET.md). It contains the shared Project instructions, source list, launch prompt, P0-W03 question queue, privacy boundary, and repository reconciliation checklist.

To continue the project in a new Codex task:

1. Obtain access to this GitHub repository and clone or open it as the Codex project folder.
2. Start a new task from the repository root.
3. Tell Codex: `Read AGENTS.md and resume from project-control/CURRENT_STATE.md. Complete the required orientation before changing files.`
4. Confirm that Codex reports CP-003 as the last approval and P0-W03 as the active work unit.
5. Use a separate branch or worktree for concurrent work and reconcile accepted results through the guided checkpoint before merging.

Because `AGENTS.md`, `CURRENT_STATE.md`, the append-only session log, the signed artifacts, and the master decision log are checked in, a collaborator can reconstruct the approved working context without access to the original chat. They should not assume that personal Codex memories, uncommitted changes, local credentials, connected apps, or the original transcript are available.

## Data boundary

Repository content must remain synthetic or anonymized. Do not commit customer names, phone numbers, email addresses, home addresses, measurements, photographs, quotes, credentials, private integration payloads, or production exports.

Markdown is authoritative. A Word distribution copy is generated only at a final release or explicit sharing milestone.
